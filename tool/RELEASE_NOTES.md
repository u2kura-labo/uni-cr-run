**Conflict Record Capture**：クリスタルコンフリクトのリザルト画面を撮って、戦績を `matches-日付.jsonl` に保存する Windows 用ツールです。

**使い方**

1. `ConflictRecordCapture.exe` をダウンロードして起動する（インストール不要）
2. 最初に出る設定で、自分のキャラクター名を入れる
3. FF14 を「ボーダーレスウィンドウ（仮想フルスクリーン）」か「ウィンドウモード」にする
4. リザルト画面で、画面に出ている小さなクリスタルのボタン（またはホットキー `Ctrl+Shift+F12`）を押す
5. 保存フォルダ（初期値：ドキュメント\Conflict Record）の **「1_戦績_ビューアに入れる」フォルダ**にある `matches-日付.jsonl` を、ビューア（https://u2kura-labo.github.io/uni-cr-run/）にドロップする

**名前とワールド名が正しく読めるようになりました**：この2つはラテン文字なのに、Windows の文字認識（日本語）で読んでいたため、`r` が `「` になる、短い名前が丸ごと落ちる、といったことが起きていました。英語だけの文字認識をアプリに同梱し、この2列だけそちらで読むようにしました。**追加のインストールは要りません。** 実際のスクリーンショットで、名前が 8/10 → 10/10 になりました。

**保存先をフォルダで分けました**：保存フォルダの下が `1_戦績_ビューアに入れる` / `2_スクリーンショット` / `3_読み取りログ` の3つに分かれます。ビューアに入れるのは 1 番のフォルダの中身です（3 番は読み取りに失敗したときの手がかりで、ビューアには入れません）。

**チームの判定が逆になる不具合を直しました**：画面の配色（アストラが赤・アンブラが青）を決め打ちで逆に見ていたため、自分の勝敗が反対に記録されていました。0.3.0 以前で保存した戦績は、勝敗とチームが入れ替わっている可能性があります。

設定の窓の右上に、いま動いているバージョンが出ます（exe を入れ替えられたかの確認に使えます）。

**読み取りの精度を上げました**：K / D / A の列だけを拡大して読み直すようにし（丸ごと落ちることがあったため）、チーム合計が読めなくても勝敗が決まるようにし、名前とワールド名の読み違い（`Kura` が `Ku` になる、`Unicorn` が `Unicon` になる など）を直しました。

画面に出るのはボタン 2 つです。クリスタルで撮影、隣の歯車でメニューが開きます。メニューからは、自分のジョブ・次の試合のマップの指定、保存フォルダを開く、既存のスクリーンショットから読み込む、設定、**撮影の停止と開始**、**終了**ができます（ボタンの右クリックでも同じメニューが開きます）。

**はじめて起動するとき**

署名していない exe なので、Windows の「PC が保護されました」という画面が出ることがあります。「詳細情報」→「実行」で起動できます。

**個人用です**

他のプレイヤーの名前が入ったデータや、その画面のスクリーンショットを共有しないでください。作成したファイルには、あなたのキャラクター名が入ります。

**このツールがすること・しないこと**

- 画面に映っているリザルト画面を撮って、Windows の文字認識（OCR）で読むだけです
- ゲームのメモリ・通信・ファイルには触れず、ゲームへのキー入力も送りません
- 読み取った戦績はこの PC の中にだけ保存し、どこにも送信しません
