**Conflict Record Capture**：クリスタルコンフリクトのリザルト画面を撮って、戦績を `matches-日付.jsonl` に保存する Windows 用ツールです。

**使い方**

1. `ConflictRecordCapture.exe` をダウンロードして起動する（インストール不要）
2. 最初に出る設定で、自分のキャラクター名を入れる
3. FF14 を「ボーダーレスウィンドウ（仮想フルスクリーン）」か「ウィンドウモード」にする
4. リザルト画面で、画面に出ている小さなクリスタルのボタン（またはホットキー `Ctrl+Shift+F12`）を押す
5. 保存フォルダ（初期値：ドキュメント\Conflict Record）の `matches-日付.jsonl` を、ビューア（https://u2kura-labo.github.io/uni-cr-run/）にドロップする

ボタンの右クリックで、自分のジョブ・次の試合のマップの指定、保存フォルダを開く、既存のスクリーンショットから読み込む、などができます。

**はじめて起動するとき**

署名していない exe なので、Windows の「PC が保護されました」という画面が出ることがあります。「詳細情報」→「実行」で起動できます。

**このツールがすること・しないこと**

- 画面に映っているリザルト画面を撮って、Windows の文字認識（OCR）で読むだけです
- ゲームのメモリ・通信・ファイルには触れず、ゲームへのキー入力も送りません
- 読み取った戦績はこの PC の中にだけ保存し、どこにも送信しません
